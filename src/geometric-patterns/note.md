# 幾何学パターン 読書メモ

## 対称操作は4つしかない

回転・並進・鏡映・映進。

## 次数 (order)

**次数 = 何回まわしたら元に戻るか。** 円を n 等分する数だと思えばいい。

- 正三角形 🔺 … 120°ずつ3回で戻る → 次数3
- 正方形 ⬛ … 90°ずつ4回 → 次数4
- 雪の結晶 ❄️ … 60°ずつ6回 → 次数6

次数 n = 1回 360/n 度まわす。n 回で一周して戻る。

## 回転対称を決めるのは2つ

1. **次数** … 何度まわすか (360/n)
2. **中心点の位置** … 要素に対してどこを軸に回すか

角度が同じでも中心点の場所が違うと別物になる。例: 次数2 (180°) の f でも、
中心を離せば2つの f が向かい合い、中心を f にくっつければ絡み合って連結する。

## 並進対称 (1.2) = fract のタイリング

同じ図形を一定距離ずらして並べるだけ。回転も鏡映もなし。いちばん素直な対称。
シェーダーでは `fract(p * n)` で座標を畳むと、全マスが同じ1個を見る = 既習のタイリングそのもの。
並進は新しい技じゃなく **`fract` に名前がついただけ**。

## 4つの対称操作 = 座標をどう畳むか

| 対称操作 | 畳み方 | 座標系 |
|---|---|---|
| 回転 | 角度を `mod` / `floor` | 極座標 |
| 並進 | `fract` | 直交座標 |
| 鏡映 | `abs` で折り返し | 直交座標 |
| 映進 (グライド) | 並進 ∘ 鏡映 (`fract` × `abs` の合わせ技) | 直交座標 |

※本文の「グライド」は 1.2 では単なる並進の意味。あとの**映進 (グライド・リフレクション) = 並進+鏡映**と紛らわしいので注意。

## 並進のツマミ (1.2 バリエーション) = 既習パーツの組合せ

| 本のツマミ | シェーダーでは | 既習 |
|---|---|---|
| 間隔 (スペーシング) | タイルの周波数 `p * n` の n。狭いと鎖状 | タイリング |
| エレメントの回転 | 並べる前にモチーフを固定角だけ回す = 回転 ∘ タイリング (セル内座標を `rot(θ)`) | 08 rotate |
| ステップ (階段状ずらし) | 並進ベクトルが斜め。行ごとに半歩オフセット = せん断 | 09-brick のレンガずらし |

- どれも `fract` タイリング + セル内で回転/オフセット だけで作れる。新しい柱は増えない。
- **非対称な図形ほど対称操作が目立つ**: q を 180° 回すと b/p に化ける。元の形の対称性で見え方が激変する。

## 鏡映対称 (1.3) = abs で軸折り

4つの中でいちばん馴染み深い (顔・体など自然界だらけ)。シェーダーでは `abs` 一発。

- 軸で折る … `p.x = abs(p.x - axis)` → 軸の右の形が左に鏡像として現れる
- **間隔** = 要素を軸からどれだけ離すか (`axis` の位置)。近いと重なってコンパクト、遠いと左右に開く。
  本文「鏡が重なると面白いモチーフが発生」= 折り返しで h と反転h が食い込み新しい字が生まれる創発。
- **回転** = 折る前に `rot(θ)` してから `abs`。**間隔+回転** で p33 のルーン文字みたいな群になる。
- **鏡映はバリエーションが少ない** (本文): 自由度が軸の位置と要素の角度くらいしかない
  (回転の次数のように無限に刻めない)。操作は簡単だが幅は狭い。

これで4本の対応が揃った → [[necessity-driven-tracks]] 並進=`fract` / 鏡映=`abs` / 回転=極座標 mod / 映進=`fract`∘`abs`。

## 映進対称 (1.4) = 並進してから鏡映 (交互鏡映)

**並進 → 進む向きと平行な線で鏡映** の合わせ技。回転と間違われがちだが決定的に違う。

- 例: **砂浜の足跡**。左足→右足→左足…= 一歩進んで鏡で反転。
  もし回転なら足が上下逆さになる (鏡像=左右反転にならない)。
- 違いは **手性 (キラリティ)**: 映進は鏡だから左右の手が入れ替わる、回転は点対称でひっくり返るだけ。
  左右非対称な形 (足・t・f) でハッキリ差が出る → 本がずっと非対称な字を使う理由。
- シェーダー: `fract` ∘ `abs` の合わせ技。ミソは **一歩ごとに交互に鏡映**。
  x をタイル化 → タイル番号 `i=floor(x)` が奇数のマスだけ `y` を反転 → 足跡状に1個おきに鏡像。

## なぜ4つだけ? = 2×2 で埋まるから (映進だけが本当の組合せ)

対称操作は **2つの軸**で完全に分類される:
- **裏返すか?** (手性を反転 = 鏡を含むか)
- **固定点があるか?** (回転中心・鏡軸のような動かない点/線を持つか)

| | 固定点あり | 固定点なし (ずれる) |
|---|---|---|
| **裏返さない** | 回転 | 並進 |
| **裏返す** | 鏡映 | **映進** |

4種類なのはこの表が 2×2 だから。「あと1個」の枠がそもそも無い。

**どう組み合わせても表の4マスに必ず戻る** (= 合成について閉じた群 E(2)):
- 並進+回転 → **ただの回転** (中心がズレるだけ。5個目にならない)
- 鏡映+鏡映 → 並進(平行) or 回転(交差)
- 鏡映+並進 → 鏡と平行にずらすと**映進**、垂直だとただの鏡映

映進が特別なのは「裏返す×固定点なし」のマスが、単独の鏡映でも並進でも埋められない
(軸と並進が平行で滑り+裏返しがほどけない)から。だから“組合せ”に見える。

### folding 言葉に翻訳すると同じ 2×2
- 裏返す = `abs` (フリップ) を挟むか / 固定点あり = 点・線で畳む(mod, abs)、なし = `fract` で滑らせる
- → **4つの folding = {flip する/しない} × {点で畳む/滑らせる}**。表がそのまま実装。
- これは後で **壁紙群17種を「4操作の組合せ」で読む土台**になる (README ロードマップの狙い)。

# Part 2 線形対称 (フリーズ / 装飾帯)

## 「フリーズ群」とは (用語)

- **フリーズ** = デザイン用語。横に長い**装飾帯** (リボン・編みボーダー・建築の飾り帯)。数学とは無関係。
- **群 (group)** = 数学用語 (群論)。ここでは実用上「分類・種類」の意味。
- **フリーズ群 = 帯状の繰り返し模様を対称性で分類したもの → ちょうど7種類**。
  どんな凝った帯柄も必ずこの7つのどれかに入る。1次元だから7、2次元(壁紙群)だと17。
- なぜ「群」: 模様を変えずに済む操作 (ずらす/折る/回す/映進) の集まりが、群の性質
  (①合成しても中に閉じる ②単位元=何もしない ③逆操作がある ④結合法則) を満たすから。
  → [[necessity-driven-tracks]] の「4操作は合成しても4つに戻る(閉じてる)」が①そのもの。既に群を触ってた。

帯に沿った1次元リピート。**7種類**あり、全部が Part 1 の4操作の組合せ = 既習の道具で作れる。

- **背骨は必ず並進** (横に `fract` で無限リピート)。これが無いと1次元にならない。
- そこにオプションで **縦の鏡映 / 横の鏡映 / 180°回転 / 映進** を足す → 足し方の違いでちょうど**7通り** (7フリーズ群)。
- 注意①: **回転だけでは線形対称は作れない** (点まわり0次元だから)。並進と組めばOK。
- 注意②: 帯で許される回転は **180°だけ** (次数2)。90°等は帯からはみ出て「線に沿う」条件が壊れる。
  → 万華鏡(02)で次数自由だったのと対照的。**1次元に閉じ込めると回転が180°に制限**。
- 用語注意: **linear symmetry (線形対称=この章)** と **line of symmetry (対称軸=鏡の軸線)** は別物。
- folding: `fract`(横) を土台に `abs`(縦/横)・180°回転(`-p`)・映進(交互`abs`) を乗せる/乗せないの7パターン。

## 7つのフリーズ群 一覧 (2.1〜2.7)

すべて「横並進 `fract(x)` が背骨」で、そこに何を足すかの違い。字は非対称 (F/Q/P) を使うと差が見える。

| 節 | 足すもの | 例 | folding (横 `fract(x)` に追加) |
|---|---|---|---|
| 2.1 | なし | F F F F | (なし) |
| 2.2 | 垂直鏡映 | Q ᗡ Q ᗡ (鏡像ペア) | セル内で `abs(x)` |
| 2.3 | 180°回転 | P d P d (点対称ペア) | 交互に `-p` (点対称) |
| 2.4 | 映進 | 足跡・鎖 | 交互に `abs(y)` (並進してから横鏡) |
| 2.5 | 水平鏡映 | 上下ミラーの2段 | `abs(y)` (中心線で上下折り) |
| 2.6 | 垂直+水平鏡映+180°回転 | 三角格子 (最も対称) | `abs(x)` + `abs(y)` (両方折り) |
| 2.7 | 垂直鏡映+映進+180°回転 | ジグザグ絡み鎖 | `abs(x)` + 交互 `abs(y)` |

- **2.2(鏡) と 2.3(回転) の違い = 手性**: P→鏡だと ꟼ、回転だと d。対称な字(H,O)だと区別がつかない。
- **「2つ目の変数」**: 2.2 以降は間隔が2種類 (①要素↔軸/中心 ②モチーフ↔モチーフ) になり別々に動かせる。
- 標準名(参考): 2.1 hop / 2.4 step / 2.2 sidle / 2.3 spinning hop / 2.5 jump / 2.6 spinning jump(p2mm) / 2.7 spinning sidle(p2mg)。

## なぜ180°だけ? / なぜ7個?

**180°だけ**: フリーズは「帯 (横に無限・縦は有限)」。対称操作は帯が帯のまま重なる必要がある。
- 90°回転 → 横の帯が縦向きになり上下にはみ出る = アウト。
- 180°回転 → 横のまま (左右反転だけ) で帯に収まる = セーフ。
- 02の万華鏡は中心1点だけで並進の制約なし → 次数自由だった。帯は「横に並進しながら」なので
  並進と両立する回転が180°(次数2)だけに絞られる。**閉じ込める次元が増えるほど回転の自由が減る**。
- 2次元(壁紙群)だと並進が縦横2方向 → 回転は 2,3,4,6回が復活。ただし**5回と7回以上は不可 = 結晶学的制限**。

**7個**: 並進は必須。帯と両立するオプションは 縦鏡・横鏡・180°回転・映進 の4つだけ。
だが 2⁴=16 にはならない。**2つ足すと3つ目が自動で生える**から:
- 横鏡 + 180°回転 → 縦鏡が勝手にできる / 縦鏡 + 横鏡 → 交点に180°回転が勝手にできる
- こうした「相棒が強制される」縛りで 16→7 に潰れる。群の①閉じてる (合成結果まで含む) が効く。

## 結晶学的制限 (crystallographic restriction)

**並進で無限に繰り返す模様で許される回転は 2・3・4・6回だけ。5回と7回以上は不可。**
- 名の由来: 結晶=原子が周期的に並んだもの → この制限が結晶の形を縛るから。
- 直感 (同じ正多角形1種で床を埋める): 三角形/正方形/六角形 ✅、**正五角形 ❌ (すき間ができる)**、七角形以上 ❌。
- 理由: 回転した先にも格子点がピッタリ来る条件を詰めると n∈{1,2,3,4,6} しか残らない (5,7+ は格子が閉じない)。
- FP/圏っぽく: 格子 (自由アーベル群 ℤ²) と n回回転が同時に保たれる n が {1,2,3,4,6} に限られる整合条件。
- 抜け道: **準結晶 (quasicrystal, 1982発見)** = 並進周期を持たないのに5回対称。「周期的なら不可」の“周期的なら”を外した。
  数学版が**ペンローズ・タイル**。(2011ノーベル化学賞)

# Part 3 平面対称 (壁紙群 17種)

並進の背骨が **1本→2本** (縦横 `fract(x)` と `fract(y)`)。1次元7種 → 2次元 **17種 (壁紙群)**。
新要素は**格子の形**: 正方形/長方形/菱形/斜方/**六角(60°120°)**。次数は結晶学的制限で 1,2,3,4,6 のみ → 17で打ち止め。
17 ≈ {格子の形} × {回転次数} × {鏡・映進の有無} の矛盾なく成立する組合せ。

## 3.1 並進 (p1) とハーフドロップ

- 平面 p1 = セルを縦横に `fract(vec2)` で敷くだけ。分類はまだ並進だけ。
- **ハーフドロップ (別名ハーフステップ)** = 1列ごとにタイルを半分ずらす。碁盤の目っぽさが消えて有機的に。
  = 既習の **09-brick のレンガずらし**をモチーフ全体でやっただけ。行でやればハーフブリック。
- ポイント: **並進の2方向が直角でなくなる (斜方格子)**。分類は p1 のままだが、基底ベクトルの取り方で見た目が激変。
  → Part 3 冒頭「格子の形が効く」の第一歩。
- folding: `let drop = 0.5*f32(col%2); q = fract(vec2f(x, y+drop))-0.5;` ドロップ量を変えれば 1/3ドロップ等も自在。

## 3.2 映進 (平面) — なぜ錯覚っぽく見えるか

平面の映進 (並進してから鏡映) は目の錯覚みたいにザワつく。理由3つ:
- **図地反転**: b と d は鏡像ツイン。b の段と d の段が交互で「どっちが図?」と脳が迷う。
- **斜めグルーピング**: コピーが斜めにずれた鏡像 → 目が勝手に斜め筋にまとめ、視線で流れて見える (動かないのに動く)。
- **centered 格子**: 映進の格子は単純な碁盤に乗らない → 繰り返しの1単位を探し続けて模様が揺れる。
- Part 1 の「映進だけ本当の組合せ・ほどけない」が視覚にもそのまま。傾いたセル(菱形/平行四辺形)だと一層強い。
