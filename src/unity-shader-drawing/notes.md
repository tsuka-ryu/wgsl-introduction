## ツール / リソース

### Graph Toy (iq) — http://www.iquilezles.org/apps/graphtoy/

数式を打つと即グラフになる関数描きツール。**シェーダの組み込み関数がそのまま使える**(`sin`,`cos`,`floor`,`fract`,`abs`,`smoothstep`,`mix`,`noise`…)。
横軸=`x`、縦軸=関数値。`f1(x)`〜`f6(x)` に式を入れる/ドラッグでパン/スクロールでズーム。`f3(x): f1(f2(x))` と互いに参照(合成)も可。

- シェーダに入れる前に「その関数がどんな波か」を目で確認できる = シェーダの断面図を描く砂場。BoS 05章シェイピング関数の実験場。
- 例:
  - `fract(x)` → ノコギリ波 / `abs(sin(x))` → 丸い山(周期π)
  - `abs(sin(x*3))` → 山が密に(= リングの周波数 `d*30` の正体)
  - `step(0.5, abs(sin(x)))` → 矩形波(= 白黒リングの断面)
  - `fract(sin(x)*43758.5)` → 砂嵐(= 10章の擬似乱数ハッシュ)

**Q. 陰関数(例: ハート `x²+(y-√|x|)²=1`)は Graph Toy にかけられる?**
A. そのままは不可(Graph Toy は `y=f(x)` の1価関数のみ)。**y について解いて複数の explicit に割る**とかける。
- `(y-√|x|)² = 1-x²` → `y = √|x| ± √(1-x²)` の2本:
  - `f1(x) = sqrt(abs(x)) + sqrt(1 - x*x)` … 上のふくらみ
  - `f2(x) = sqrt(abs(x)) - sqrt(1 - x*x)` … 下のとがり
- 2本を同時に描くと合わさってハート。`|x|>1` は `sqrt` が NaN で描かれず x∈[-1,1] だけに出る
- 「陰関数は y で解いて複数の explicit に割る」は SDF/距離場を考える時の頭の体操にもなる

## テクニックについて

### ディスタンスフィールド

定義: ある場所からの**距離**に基いて空間を解釈する = `平面 → 距離(スカラー場)` を作る。

**`distance(a, b)`** … `f32` スカラーを返す (ベクトルを入れてもスカラー)。以下は全部等価:
- `distance(a, b)` … 2点間の距離を一発で
- `length(a - b)` … 差ベクトルの長さ
- `sqrt(dx*dx + dy*dy)` … ピタゴラスを手で (= length の中身)

型は `distance : (vec2f, vec2f) → f32`。3D でも返りは `f32`。GLSL/WGSL/HLSL 同名。

**Q. 距離をそのまま返すと色が変わるのは、遠いほどスカラーが大きいから?**
A. その通り。HLSL の `return d;` は `float→float4` 自動 broadcast で `(d,d,d,d)` = グレースケールの明暗。
- 中心 `(0.5,0.5)` → `d=0` → 黒
- 離れるほど `d` 増 → 明るい。角で `d≈√0.5≈0.707` 止まり = 真っ白にはならない (`d*2` で飛ばせる)
- 生の `d` は距離"場"そのもの。`step(0.5, d)` を噛ませば 0.5 で2値化 → 円が出る
- ※WGSL はスカラー→ベクトルの暗黙 broadcast 不可。`vec4f(vec3f(d), 1.0)` と明示が必要

**step と smoothstep** (距離場を「切る」道具):
- `step(edge, x)` → `{0, 1}` の2値・崖。`x≥edge`で1。境界はギザギザ(ジャギー)
- `smoothstep(a, b, x)` → `[0,1]` 連続・なめらかな坂。`x≤a`で0/`x≥b`で1/間はS字
- 距離場を step で切る=くっきり図形、smoothstep で切る=ぼんやりグロー
- 第1引数がしきい値(edge)。GLSL/WGSL/HLSL 共通

**同心円リング**: 距離場を「輪切り」にしてリングを作る。3段の合成:

```
色 = step で2値化(任意) ∘ 周期関数で輪切り ∘ 距離場
   = step(0.5,           周期関数(          distance(中心,uv) * 周波数 ))
```

**① 周期関数**(繰り返す波を作る部品。どちらでもリングになる):
- `fract(d*N)` … **`fract(x) = x - floor(x)` = 小数部だけ取り出す**。`fract(3.7)=0.7`, `fract(0.2)=0.2`。
  入力が増えると `0→1` を延々くり返す**ノコギリ波**(`0.9→1.0` の次が急に `0.0` に落ちる段差)。HLSL では `frac`
- `abs(sin(d*N))` … `sin`(`-1〜1`,周期`2π`)を `abs` で折り返し `0〜1`(周期`π`)の**丸い波**。山の頂=明るい輪
- `N`(周波数)でリング本数が決まる。`abs(sin(d*30))` なら `30/π≈9.5` 本

**② step の有無**(仕上げ):
- なし → 柔らかいグラデリング(ふわっと滲む)
- `step(0.5, …)` あり → 丸い山が**矩形波**に化けて**白黒くっきり**リング

→ ①②どの組合せでも同心円リング。デッキは `step(0.5, abs(sin(d*30)))` を見せた。

**補足**: `abs(sin)` は BoS では「薄い等高線」の脇役(`color -= abs(sin(...))*0.07`)。
デッキは同じ部品を絵の主役に格上げしただけで、新手法ではない。
BoS 対応: `fract`版=`07-distance-field` / `abs(sin)`版=`12-cells-df`,`12-voronoi` 等

**座標系の2流儀** (混乱しがち。まず「今の st はどっち基準か」を確認):

| 流儀 | 範囲 | 中心 | 使う場面 |
|---|---|---|---|
| UV そのまま | `0〜1` | `(0.5, 0.5)` | 素直な距離・タイリング |
| 中心原点 | `−1〜+1` | `(0, 0)` | 対称折り畳み(`abs`)・回転・極座標 |

- 見分け方: コード頭に `st*2-1` や `st-0.5` があれば中心原点、無ければ `0〜1` のまま
- `abs(st)` で折り畳む系は**中心0が前提**。0.5基準のままだと畳まれず別物になる

**距離メトリクスで等高線の形が変わる** (「中心からの距離」でも測り方次第):

| 式 | 距離 | 等高線 |
|---|---|---|
| `length(st)` | L2 ユークリッド | 円 |
| `abs(st.x)+abs(st.y)` | L1 マンハッタン | ひし形 |
| `max(abs(st.x),abs(st.y))` | L∞ チェビシェフ | 正方形 |
| `length(max(abs(st)-b, 0))` | box SDF | 角丸四角 |

**注意: `length(abs(st)-0.3)` は素直な円ではない** (`07-distance-field` の既定式):
- `d=0` になるのは4点 `(±0.3,±0.3)`。中心1個の円でなく「4点への距離＝四つ葉」模様
- `abs` の折り畳み境界(x/y軸)に尾根ができ、等高線がそこで角ばる
- 真円リングが見たければ選択行を `length(st)` に差し替え

**Cellular noise (Worley) も距離場**: ターゲットが「1点」→「最寄りの点」に変わっただけ。
`色 = min over i: distance(uv, 点ᵢ)` (点の近く=谷=暗い)。BoS `12-cells-df`, `12-cellular-noise`。

*ランダムに点を打つ仕組み* (シェーダには点を保存する配列が無い → **点の位置を座標の純関数にする**):
1. `st*=3; i_st=floor(st)`(マスの住所=整数)/`f_st=fract(st)`(マス内0〜1)。平面をマス目に分割
2. `random2(i_st)` = 住所→マス内の点位置(0〜1)。**純関数**なので同じ住所は毎回同じ点=保存不要
   - `random2(p)=fract(sin(vec2(dot(p,k1),dot(p,k2)))*43758.5)`。10章ハッシュの2成分版
   - `sin`→`-1〜1`, `*巨大数`→隣と無相関に, `fract`→`0〜1`(点が必ずマス内に収まる)
   - 入力=住所(整数) / 出力=マス内ローカル位置。x用y用に別係数で2次元に散らす
3. → 各マスに点が1個ずつ「ランダム配置」された状態が、保存なしで全ピクセル共通に復元できる

*最寄り点を探す (3×3 の min)*:
- 自分のマスの点だけ見ると、マス境界で「隣マスの点の方が近い」を取りこぼし距離が不連続に飛ぶ
- → 自分+隣接8マス=**3×3の9点すべてに距離を測り `min` で最短だけ残す**
- 点は必ずマスの `[0,1]²` 内 → 最寄りは絶対に3×3内。点が何個でも常に9マス=定数コスト
- 座標揃え: `diff = neighbor + point - f_st`(隣マスのローカル点を自分のマス基準に並べ直す→自分→点ベクトル)
- `色(uv) = min over (dx,dy)∈{-1,0,1}² distance(uv, 該当マスの点)` … fBm の `Σ` と同じ畳み込みの min 版

*出力の見え方* (色 = 最寄り点までの距離なので):
- **黒い中心 = 点そのもの**(距離0で最小)。明るいほど点から遠い
- 明るい稜線 = 2点から等距離(垂直二等分線=セル境界) / 明るい角 = 3点から等距離の最遠点
- 「他のマスの点」は隣の**黒いブロブ**。明るい角は点ではなく点から一番遠い谷間(逆)
- `min`→`argmin`(どの点が最寄りか)で塗ると縄張り分割=**ボロノイ**(`12-voronoi`)

*なぜ最寄り距離が欲しいか (目的)*: それを塗ると「ランダムだが構造のある模様」=素材になるから。
自然物のテクスチャ(石・肌・水・地面)を数式だけで生むノイズの部品。距離場1枚から応用が枝分かれ:
- そのまま=細胞/水面 / `abs(sin)`等高線=ひび割れ・岩 / `argmin`=ボロノイ / `F2−F1`=結晶のヒビ

*★キモ: 点はピクセルでなく「マスの持ち物」*:
- `random2` の入力は `i_st=floor(st)`=**マスの住所**。マス内のどのピクセルでも同じ整数 → 同じ点が返る
- だからマス内の全ピクセルが「うちの点はここ」と**全員一致**できる(保存なしで矛盾しない)
- `floor`(住所)=マス内で一定 / `fract`(ローカル位置)=ピクセルごとに連続、という分解がタイル系全部の賢さ
