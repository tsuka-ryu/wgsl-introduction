## 全体像 (フラグメントシェーダお絵描きの地図)

**本質**: フラグメントシェーダ = `色 = 純関数(座標)` 型 `ℝ² → color`。全シェーダがこの1行(各ピクセルの座標→色)。

その中間で使う「場」の作り方は大きく3系統。デッキの5技法もここに畳まれる:

$$色 = \underbrace{色付け}_{step/sin/mix} ∘ \underbrace{場}_{距離 or ノイズ} ∘ \underbrace{座標変換}_{極座標/タイル/歪み}$$

| 段 | 型 | 仕事 | デッキの技法 |
|---|---|---|---|
| 座標変換 | `座標→座標` | 平面をこねる(前処理) | 極座標・歪み・繰り返し(3つ) |
| 場 | `座標→値` | スカラー値を作る | ディスタンスフィールド / 擬似乱数(ノイズ) |
| 色付け | `値→色` | 数を色に翻訳 | (step/sin/mix など随所) |

- **距離場は「場」スロットの花形(幾何・図形担当)**。でも "全ての本質" ではない=柱の1本
- **ノイズ(Perlin/simplex)は距離場ではない**(格子勾配の補間、距離を測ってない)。fBmも距離ゼロ。
  Worley(セルラー)だけが「距離ベースのノイズ」で両者の交差点
- デッキの5技法: 距離場=1 / 座標変換=3(極座標・歪み・繰り返し) / 乱数=1 → 距離場は5つのうちの1つ
- **3D(レイマーチング)では距離場(SDF)がほぼ本質に昇格**(空間全体を表面までの距離で表し光線を進める)
- あなたの志向との対応: 「絵=純関数の合成」そのもの。部品(distance/min/Fₙ/noise)を自由合成 [[user-fp-pl-background]]

## ツール / リソース

### Graph Toy (iq) — http://www.iquilezles.org/apps/graphtoy/

数式を打つと即グラフになる関数描きツール。**シェーダの組み込み関数がそのまま使える**(`sin`,`cos`,`floor`,`fract`,`abs`,`smoothstep`,`mix`,`noise`…)。
横軸=`x`、縦軸=関数値。`f1(x)`〜`f6(x)` に式を入れる/ドラッグでパン/スクロールでズーム。`f3(x): f1(f2(x))` と互いに参照(合成)も可。

- シェーダに入れる前に「その関数がどんな波か」を目で確認できる = シェーダの断面図を描く砂場。BoS 05章シェイピング関数の実験場。
- 例:
  - `fract(x)` → ノコギリ波 / `abs(sin(x))` → 丸い山(周期π)
  - `abs(sin(x*3))` → 山が密に(= リングの周波数 `d*30` の正体)
  - `step(0.5, abs(sin(x)))` → 矩形波(= 白黒リングの断面)
  - `fract(sin(x)*43758.5)` → 砂嵐(= 10章の擬似乱数ハッシュ)

**Q. 陰関数(例: ハート `x²+(y-√|x|)²=1`)は Graph Toy にかけられる?**
A. そのままは不可(Graph Toy は `y=f(x)` の1価関数のみ)。**y について解いて複数の explicit に割る**とかける。
- `(y-√|x|)² = 1-x²` → `y = √|x| ± √(1-x²)` の2本:
  - `f1(x) = sqrt(abs(x)) + sqrt(1 - x*x)` … 上のふくらみ
  - `f2(x) = sqrt(abs(x)) - sqrt(1 - x*x)` … 下のとがり
- 2本を同時に描くと合わさってハート。`|x|>1` は `sqrt` が NaN で描かれず x∈[-1,1] だけに出る
- 「陰関数は y で解いて複数の explicit に割る」は SDF/距離場を考える時の頭の体操にもなる

### 座標・記号
- `st` = 正規化した画面座標。**0〜1(中心0.5)** か **−1〜+1(中心0)** の2流儀(コード頭の`*2-1`有無で判別)
- `uv` = メッシュのテクスチャ座標(Unity)。`st`相当
- `argmin` = 最小値を出した「引数(点)」。`min`=最小の値 / `argmin`=それを出した入力
- broadcast = スカラー→ベクトル自動拡張(HLSL: `return d;`で`float→float4`)。WGSLは不可(明示`vec4f(...)`)

## テクニックについて

### ディスタンスフィールド

定義: ある場所からの**距離**に基いて空間を解釈する = `平面 → 距離(スカラー場)` を作る。

**`distance(a, b)`** … `f32` スカラーを返す (ベクトルを入れてもスカラー)。以下は全部等価:
- `distance(a, b)` … 2点間の距離を一発で
- `length(a - b)` … 差ベクトルの長さ
- `sqrt(dx*dx + dy*dy)` … ピタゴラスを手で (= length の中身)

型は `distance : (vec2f, vec2f) → f32`。3D でも返りは `f32`。GLSL/WGSL/HLSL 同名。

**Q. 距離をそのまま返すと色が変わるのは、遠いほどスカラーが大きいから?**
A. その通り。HLSL の `return d;` は `float→float4` 自動 broadcast で `(d,d,d,d)` = グレースケールの明暗。
- 中心 `(0.5,0.5)` → `d=0` → 黒
- 離れるほど `d` 増 → 明るい。角で `d≈√0.5≈0.707` 止まり = 真っ白にはならない (`d*2` で飛ばせる)
- 生の `d` は距離"場"そのもの。`step(0.5, d)` を噛ませば 0.5 で2値化 → 円が出る
- ※WGSL はスカラー→ベクトルの暗黙 broadcast 不可。`vec4f(vec3f(d), 1.0)` と明示が必要

**step と smoothstep** (距離場を「切る」道具):
- `step(edge, x)` → `{0, 1}` の2値・崖。`x≥edge`で1。境界はギザギザ(ジャギー)
- `smoothstep(a, b, x)` → `[0,1]` 連続・なめらかな坂。`x≤a`で0/`x≥b`で1/間はS字
- 距離場を step で切る=くっきり図形、smoothstep で切る=ぼんやりグロー
- 第1引数がしきい値(edge)。GLSL/WGSL/HLSL 共通

**同心円リング**: 距離場を「輪切り」にしてリングを作る。3段の合成:

```
色 = step で2値化(任意) ∘ 周期関数で輪切り ∘ 距離場
   = step(0.5,           周期関数(          distance(中心,uv) * 周波数 ))
```

**① 周期関数**(繰り返す波を作る部品。どちらでもリングになる):
- `fract(d*N)` … **`fract(x) = x - floor(x)` = 小数部だけ取り出す**。`fract(3.7)=0.7`, `fract(0.2)=0.2`。
  入力が増えると `0→1` を延々くり返す**ノコギリ波**(`0.9→1.0` の次が急に `0.0` に落ちる段差)。HLSL では `frac`
- `abs(sin(d*N))` … `sin`(`-1〜1`,周期`2π`)を `abs` で折り返し `0〜1`(周期`π`)の**丸い波**。山の頂=明るい輪
- `N`(周波数)でリング本数が決まる。`abs(sin(d*30))` なら `30/π≈9.5` 本

**② step の有無**(仕上げ):
- なし → 柔らかいグラデリング(ふわっと滲む)
- `step(0.5, …)` あり → 丸い山が**矩形波**に化けて**白黒くっきり**リング

→ ①②どの組合せでも同心円リング。デッキは `step(0.5, abs(sin(d*30)))` を見せた。

**補足**: `abs(sin)` は BoS では「薄い等高線」の脇役(`color -= abs(sin(...))*0.07`)。
デッキは同じ部品を絵の主役に格上げしただけで、新手法ではない。
BoS 対応: `fract`版=`07-distance-field` / `abs(sin)`版=`12-cells-df`,`12-voronoi` 等

**座標系の2流儀** (混乱しがち。まず「今の st はどっち基準か」を確認):

| 流儀 | 範囲 | 中心 | 使う場面 |
|---|---|---|---|
| UV そのまま | `0〜1` | `(0.5, 0.5)` | 素直な距離・タイリング |
| 中心原点 | `−1〜+1` | `(0, 0)` | 対称折り畳み(`abs`)・回転・極座標 |

- 見分け方: コード頭に `st*2-1` や `st-0.5` があれば中心原点、無ければ `0〜1` のまま
- `abs(st)` で折り畳む系は**中心0が前提**。0.5基準のままだと畳まれず別物になる

**距離メトリクスで等高線の形が変わる** (「中心からの距離」でも測り方次第):

| 式 | 距離 | 等高線 |
|---|---|---|
| `length(st)` | L2 ユークリッド | 円 |
| `abs(st.x)+abs(st.y)` | L1 マンハッタン | ひし形 |
| `max(abs(st.x),abs(st.y))` | L∞ チェビシェフ | 正方形 |
| `length(max(abs(st)-b, 0))` | box SDF | 角丸四角 |

**注意: `length(abs(st)-0.3)` は素直な円ではない** (`07-distance-field` の既定式):
- `d=0` になるのは4点 `(±0.3,±0.3)`。中心1個の円でなく「4点への距離＝四つ葉」模様
- `abs` の折り畳み境界(x/y軸)に尾根ができ、等高線がそこで角ばる
- 真円リングが見たければ選択行を `length(st)` に差し替え

**Cellular noise (Worley) も距離場**: ターゲットが「1点」→「最寄りの点」に変わっただけ。
`色 = min over i: distance(uv, 点ᵢ)` (点の近く=谷=暗い)。BoS `12-cells-df`, `12-cellular-noise`。

*ランダムに点を打つ仕組み* (シェーダには点を保存する配列が無い → **点の位置を座標の純関数にする**):
1. `st*=3; i_st=floor(st)`(マスの住所=整数)/`f_st=fract(st)`(マス内0〜1)。平面をマス目に分割
2. `random2(i_st)` = 住所→マス内の点位置(0〜1)。**純関数**なので同じ住所は毎回同じ点=保存不要
   - `random2(p)=fract(sin(vec2(dot(p,k1),dot(p,k2)))*43758.5)`。10章ハッシュの2成分版
   - `sin`→`-1〜1`, `*巨大数`→隣と無相関に, `fract`→`0〜1`(点が必ずマス内に収まる)
   - 入力=住所(整数) / 出力=マス内ローカル位置。x用y用に別係数で2次元に散らす
3. → 各マスに点が1個ずつ「ランダム配置」された状態が、保存なしで全ピクセル共通に復元できる

*最寄り点を探す (3×3 の min)*:
- 自分のマスの点だけ見ると、マス境界で「隣マスの点の方が近い」を取りこぼし距離が不連続に飛ぶ
- → 自分+隣接8マス=**3×3の9点すべてに距離を測り `min` で最短だけ残す**
- 点は必ずマスの `[0,1]²` 内 → 最寄りは絶対に3×3内。点が何個でも常に9マス=定数コスト
- 座標揃え: `diff = neighbor + point - f_st`(隣マスのローカル点を自分のマス基準に並べ直す→自分→点ベクトル)
- `色(uv) = min over (dx,dy)∈{-1,0,1}² distance(uv, 該当マスの点)` … fBm の `Σ` と同じ畳み込みの min 版

*出力の見え方* (色 = 最寄り点までの距離なので):
- **黒い中心 = 点そのもの**(距離0で最小)。明るいほど点から遠い
- 明るい稜線 = 2点から等距離(垂直二等分線=セル境界) / 明るい角 = 3点から等距離の最遠点
- 「他のマスの点」は隣の**黒いブロブ**。明るい角は点ではなく点から一番遠い谷間(逆)
- `min`→`argmin`(どの点が最寄りか)で塗ると縄張り分割=**ボロノイ**(`12-voronoi`)

*なぜ最寄り距離が欲しいか (目的)*: それを塗ると「ランダムだが構造のある模様」=素材になるから。
自然物のテクスチャ(石・肌・水・地面)を数式だけで生むノイズの部品。距離場1枚から応用が枝分かれ:
- そのまま=細胞/水面 / `abs(sin)`等高線=ひび割れ・岩 / `argmin`=ボロノイ / `F2−F1`=結晶のヒビ

*★キモ: 点はピクセルでなく「マスの持ち物」*:
- `random2` の入力は `i_st=floor(st)`=**マスの住所**。マス内のどのピクセルでも同じ整数 → 同じ点が返る
- だからマス内の全ピクセルが「うちの点はここ」と**全員一致**できる(保存なしで矛盾しない)
- `floor`(住所)=マス内で一定 / `fract`(ローカル位置)=ピクセルごとに連続、という分解がタイル系全部の賢さ

**SDF (Signed Distance Field / 符号付き距離場)**: 距離場に**符号**を足したもの。
- `SDF(p) < 0`=形の内側 / `=0`=輪郭の上 / `>0`=外側。`|SDF|`=最寄り輪郭までの距離
- 例: 円は `circleSDF(p) = distance(p,中心) - r`。`-r` で「輪郭0・内負・外正」になる
- **★気づき: 形の合成(ブーリアン)は SDF の符号に紐づく概念**。符号があるから `min`/`max` が形の足し引きになる:
  - `min(A,B)`=和集合(A∪B) / `max(A,B)`=積集合(A∩B) / `max(A,-B)`=差(A−B、Bの符号反転)
- 役割分担: 距離の測り方(L1/L2/box)=1つの形の**輪郭形状** / 符号=複数の形の**合成**を可能にする
- 符号なしの素の距離場だと `min` しても綺麗な和集合にならない。メタボール/ブーリアンは全部 SDF の土俵
- BoS: `07-sdf-combine`, `07-fields-combine`

**メタボール = 距離を掛ける (硬いブーリアンとの対比)**:
- ブーリアン `min(A,B)` は「一番浅い谷だけ残す」→ 2点の間は沈まず分離
- メタボールは距離を**掛ける** `d₁*d₂`。点の近くは `d<1` なので掛けると沈む(非線形):
  - `x²`: `0.1→0.01 / 0.5→0.25 / 0.8→0.64 / 1→1`。`x<1`で下に引っ張られ傾き`2x`で点の近くほど平ら
  - キモは同じ距離の2乗でなく**別々の2点** `d₁*d₂`。中間地点は両方の寄与で余計沈む→橋がかかり融合
- **★深い正体: 硬い/柔らかい = 微分できるか**:
  - `min(a,b)` は区分線形、交点で傾きがカクッと折れる(微分不連続=折れ目=硬い継ぎ目)
  - `a*b`(掛け算)はどこでも滑らか(微分可能、折れ目なし)=なめらかに繋がる
  - 「複数点を混ぜる=滑らかな関数で繋ぐ=微分不連続を消す」は同じ話の3つの言い方
  - `smin`(smooth-min)=`min`の角だけ丸めた関数=硬いブーリアンと柔らかいメタボールの中間
- BoS: `12-metaballs`

*実装 (`12-metaballs`, 土台は Worley と同じ 5×5タイル+3×3近傍+アニメ点)*:
- 違いは1行だけ: `m_dist = min(m_dist, m_dist * dist)` (Worley は `min(m_dist, dist)`)
- `dist<1`(近い点)→積が小さくなり採用(谷が深まる)/`dist>1`(遠い点)→`min`が却下(無視)
  → `m_dist ≈ 近くの点(<1)の距離の積`。**d₁,d₂ は選ばない。9個掛けて近い点だけ自動で生き残る**
- `step(0.06, m_dist)` で谷(<0.06)を黒に。数値トレース(点A,B が 0.4 離れ):
  - 点の上: `d=0` → `m_dist=0` → 黒(コア)
  - 2点の間: `d_A=d_B=0.2` → 積 `0.04` < 0.06 → 黒(**融合**)。※`min`なら`0.2`→白(繋がらない)
  - 孤立点から0.2: `m_dist=0.2` → 白。仲間がいる時だけ積が効いて黒が太り繋がる
- *★実験で判明*: `m_dist * dist` を `1 * dist` にすると `min(m_dist,dist)`=Worley に戻り、
  点が独立した丸ぽちになる(融合しない)。融合は `m_dist *`=**累積を持ち越すチェーン**が担う。
  `m_dist *`=点の影響を積み重ねるスイッチ、`1 *`=各点独立(相互作用ゼロ)

**ボロノイ = `min`→`argmin` (メタボール"混ぜる"の対、"分ける")** (`12-voronoi`):
- **argmin** = 最小値を出した「引数(点)」。min=最短"距離"(スカラー) / argmin=最短の"点"(vec2f=勝者)
- 実装差は1行: `min` を `if(dist<m_dist){ m_dist=dist; m_point=point[i]; }` に開き**勝者点も記録**
- 2つの情報を別々に使う:
  - `m_dist`(距離) → 明るさ/等高線/白ドット = 「どれだけ近いか」の距離場ビジュアル
  - `m_point`(勝者) → `color.rg = m_point.xy` で縄張りのベタ塗り = 「誰に属すか」(ボロノイの核)
- **なぜ領域が見えるか**: 縄張り内は最寄り点が同じ→`m_point`一定→同じ色のベタ塗り面。
  境界で勝者がパッと切り替わり色がジャンプ→段差が輪郭に見える。**誰も線は描いてない**(色の不連続が境界)
- 距離(連続グラデ)を勝者点(領域内一定・境界で不連続)に差し替えると「面」と「境界」が立ち上がる
- 境界=2点から等距離の垂直二等分線(直線)。denotational: `色 = 座標(argmin_i dist(uv,点_i))`

*セルラー vs ボロノイ = 骨格同じ・塗り方違い* (似て見える理由):
- 土台の特徴点が同じ → セルの区画は完全一致。Worleyの「明るい稜線(点から遠い所)」=ボロノイの「境界(垂直二等分線)」で**同じ線**
- 違いは fill だけ: Worley=各セルを中心暗→縁明の**連続グラデ**で塗る / ボロノイ=各セルを**一定色でベタ塗り**
- 例え: 同じ地図を「標高グラデで塗る」か「県ごと色分け」か。区画は同じ、塗り方が別
- 枝: 特徴点+最寄り探索 → 距離を塗る(`min`)=セルラー連続テクスチャ / 勝者を塗る(`argmin`)=ボロノイ領域分割

**F2−F1 のひび割れ / 立体クッション** (`12-cellular-f2`): accumulator を「1個→上位2個」に広げる:
- `F1`=最寄り距離, `F2`=2番目に近い距離。挿入で `f1≤f2` を保つ(1位登場で王者を2位に繰り下げ):
  `if(dist<f1){f2=f1;f1=dist;} else if(dist<f2){f2=dist;}`
- `F2−F1`: 境界(2点が拮抗し `F1=F2`)で **0=暗い線**、セル内側で差が開き明るい → ひび割れ
- 立体に見える理由: 各セルが中心(点)で明・縁(境界)で0 = **中央が盛り上がったドーム/クッション**。
  明るさ=高さと脳が読む。暗い谷に注目=ひび割れ / 明るい膨らみに注目=鱗・泡・宝石ファセット
- ひび割れの暗い線は**ボロノイ境界と同じ場所**(境界=F1=F2)。骨格共有がここでも効く

*★Fₙ を基底に自由合成 (Worley 1996 の枠組み)*: `F1,F2,F3…`(第n最寄り距離)を部品として `c₁F1+c₂F2+…` で無数のテクスチャ:
- `F1`=丸窪み / `F2−F1`=ひび割れ・クッション / **`F1+F2`=なだらかで丸いセル(局所的に楕円っぽい・実験で確認)** / `F3−F2`=三重点近くの別柄
- `F1=F2=F3` の所=3セルが出会う角(ボロノイ頂点)。3×3の9候補なので F9 が上限
- 「最寄り第n距離という部品を好きな式で合成」= shader-gen 言語の発想と地続き。`12-cellular-f2` に `f1+f2` 切替行あり

**ボロノイ境界までの距離 (iq voronoi edges / 網目・細胞組織)** (`12-voronoi-edges`): 同じ特徴点から取り出す第3の量:
- セルラー=点まで / ボロノイ=誰の縄張り(勝者) / これ=**最寄りの境界"線"まで**の距離
- 境界は「点」でなく「線」なので位置を先に知る必要 → **2パス**:
  - パス1: ふつうのボロノイで最寄り点Aを確定(argmin)。ピクセル→Aのベクトル `mr` を記録
  - パス2: Aと各隣接点B(5×5)の**垂直二等分線=境界**までの距離を全Bで `min`(A自身はスキップ)
- **核の式**: `dot(0.5*(mr+r), normalize(r-mr))` = 壁までの距離
  - `0.5*(mr+r)`=A,Bの**中点**へのベクトル(境界はここを通る) / `normalize(r-mr)`=**AB方向**(=境界の法線)
  - 中点ベクトルを法線(AB方向)に射影=点→直線の距離。「中点を出して AB方向に射影」が一言まとめ
- 実装メモ: `dot(r,r)`=距離²(比較だけなら`sqrt`不要=高速化) / パス2は5×5(斜め2マス先の取りこぼし防止)
- denotational: 同じ点群から `min dist(P,点)`=セルラー / `argmin`=ボロノイ / `min dist(P,二等分線)`=境界(網目)

**cellular2x2 = 高速な汎用 Worley 関数** (`12-stippling`, `12-cellular-permute`):
- 手書き Worley (for 9マス{random2→距離→min}) と**やってることは同じ**。実装を最適化しただけ:
  - ループ→**vec4 で4マス並列**(GPUは4成分を一発演算) / 3×3(9)→**2×2(4)マス** / `fract(sin)`→**permute多項式ハッシュ**
  - 上位2件は for/min でなく4成分のスワップで選り分け
- 戻り値 `vec2 = (F1, F2)`。**汎用**(F1だけ=点描/`F2-F1`=ひび割れ/`F1+F2`=丸セル に使い回せる)。今回はF1のみ
- トレードオフ: **速いがたまに不正確**(2×2だと斜めの最寄りを取りこぼす)。`jitter=0.8`で点を内寄りにして誤魔化す。点描など多少ズレてOKな用途向け

**permute = 多項式ハッシュ** (`12-cellular-permute`, cellular2x2 の中身。`fract(sin)` の production 版):
- `permute(x) = (34x²+x) mod 289` = 整数を 0〜288 の別整数に散らすハッシュ
- **置換多項式(permutation polynomial)**: 入力 0〜288 を**衝突なく並べ替える全単射**(`289=17²`, `34=2·17` の数論的選択)
- `fract(sin)` より優れる点: `mod 289` で値が暴れず float 精度が保たれ、**GPU で結果が安定**(sinは精度依存で縞が出る)
- 負座標対策: WGSL の `%` は負で符号が変 → `x - floor(x/289)*289` の床mod を自前定義
- 2D化: **nest** `permute(permute(x) + y)` で x,y を1つの乱数に。`p` を7進の桁に分けて点の x/y(=`mod7`)に
- *★衝突の話*: 2D は `289²→289` なので**鳩の巣で衝突不可避**。でもWorleyに要るのは「局所の無相関＋大きい周期」だけで**globalユニークは不要**→ 衝突OK。周期289 >> 画面の数十セルなので repeat 見えず
  - 「必要な保証は局所性だけ」= 過剰な保証を求めない設計 [[user-fp-pl-background]]
- *もっと大きい数は?*: float32 の整数精度 **2²⁴** が天井(`34x²`がこれを超えると崩壊)→ float だと N~700 が限界＆置換条件の選び直しも要る。真に大きくしたいなら **u32 整数ハッシュ(PCG等)** に乗り換え(permute は整数演算が無かった時代の遺産)

**Stippling (点描/ハーフトーン)** (`12-stippling`): 濃淡を「点の粗密」で表す。
- 材料2つ: `F.x`=Worley距離場(点の位置) × `ring`=`abs(sin(dot(pos,pos)*π*5))`=同心円の濃淡(どこを黒くしたいか)
- 合成: `n = step(ring, F.x*2)`。点の近く(F.x小)ほど黒 & ringの濃い所ほど黒点が太る
- **★原理: 滑らかな濃淡 × ランダム距離場 を step で切ると、濃淡が点の粗密に砕ける** = ハーフトーンの最小装置
- `色 = step(濃淡場, 距離場)`。濃淡側を写真輝度にすれば写真→点描変換

*詳細メモ (1行ずつ読んで判明)*:
- **一粒の点が「円」なのは、ランダム点からの距離 `F.x` を `step` で切ってるから**(07-circle-step と同型: 距離場→step=円)
  - 黒の条件 `F.x*2 < ring` ⟺ `F.x < ring/2` → 各点を中心にした**半径 `ring/2` の円**。濃い帯(ring≈1)ほど円がでかい(半径≈0.5)
- **同心円バンドになるのは `dot(pos,pos)`=中心からの距離²が「向きに無関係・距離だけ」だから**(等距離の輪で ring 一定=円対称)。`pos.x`なら縦縞/`atan2`なら放射状
  - 2つの「距離→円」が重なる: `F.x`=点の丸さ / `dot(pos,pos)`=同心円配置
- **`F.x*2` の `2` は点サイズの調整つまみ**: `F.x`は狭い範囲(~0〜0.5)なので`ring`(0〜1)と張り合うよう引き伸ばすゲイン。
  ×1=黒ベタ寄り(点が潰れる) / ×2=点が散る / ×4=小さく疎に

### 極座標

全体像の「**座標変換**」の柱: `(x,y)` を `(r=距離, θ=角度)` で表す。回転対称なもの(花・星・歯車・放射)が θ の関数1個で書ける。

- 変換: `r = length(pos)` / `θ = atan2(pos.y, pos.x)` (06-hsb-polar と同じ道具)
- **花のレシピ**: グラフの軸を読み替える → **横=角度θ / 縦=その角度での「花びらの縁の半径」 `f(θ)`**
  - 描くルール: `r < f(θ)` なら内側(白)。= **しきい値を角度で変えた step**(距離場を切るのと同型)
  - `花(pixel) = step( length(pixel), f(atan2(pixel)) )`, `f: 角度→縁の半径`
- **なぜ花びらか** (`y=abs(cos(3θ)`)): θを回すと `cos(3θ)` が振動、`abs`で山が倍 → 60°ごとに先→谷→先 = **6枚**。
  山=花びらの先(遠い)/谷(=0)=中心のくびれ。周波数で花びらの枚数が変わる
- 応用も全部 `f(θ)` の違い: `abs(cos12θ·sin3θ)`=トゲ星 / `min(abs(cos2.5θ+.4),abs(sin2.5θ+1.1))`=桜(min=形の合成がここでも)
- denotational: 座標変換`(x,y)→(r,θ)` → 場`f(θ)とrの比較` → 色付け`step`。角度で模様を定義したい時の座標系
- BoS: `07-polar-shapes`, `06-hsb-polar`, `07-polygon-sdf`(角度で辺を切り替える正N角形)

*桜を描く実装の積み上げ (デッキの7ステップ = 黄金パターン)*:
1. `distance(0, uv)` … 角(uv原点)からの距離場
2. `st = 0.5 - uv; length(st)` … 原点を画面中心へ → **中心からの距離 `r`**
3. `a = atan2(st.y, st.x)` … **角度 `θ`**(`-π〜π` → `(a+PI)/(2PI)`で0〜1可視化)。ここまでで座標変換完了
4. (角度が一周する様子)
5-6. `d = min(abs(cos(a*2.5))+0.4, abs(sin(a*2.5))+1.1)*0.32` … 角度から**縁の半径 `f(θ)`**
7. `r = length(st); step(r, d)` … `d ≥ r なら白(内側)` → 桜完成
- 黄金パターン: **r と θ を作る(2,3) → θ から縁 f(θ) を決める(6) → r と比べ step で切る(7)**
- `花(pixel) = step( length(st), f(atan2(st)) )` = 地図の `色付け ∘ 場 ∘ 座標変換` そのまま

**★新概念: マスク合成 (レイヤー塗り重ね)** ※極座標に限らず一般の色付けテク:
- `色 = lerp(下地, その層の色, マスク)` を層の数だけ重ねる (Photoshopのレイヤー)
- **マスク** = `step` で作った 0/1 の「どこを塗るか」 / **lerp(mix)** = 0=下地・1=上の色
- 例(桜): 背景グラデ → `lerp(色, 花びら色, step(r,d))` → `lerp(色, 黄, step(dist,0.07))` と重ねる
- 層の色自身にグラデも可(`lerp(ピンク,白,r)`で中心→縁)。新しい関数ゼロ、step(形)とmix(補間)の組合せ
- denotational: `色 = 層n ∘ … ∘ 層1 ∘ 背景`、各層 = `lerp(下地, 色, マスク)`。「絵=レイヤーの合成」軸
